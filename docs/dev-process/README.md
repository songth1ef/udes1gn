# 开发过程文档 / dev-process

> 记录自动化构建过程的状态、自审、修复、测试。供随时回看进度，明早可看每步发生了什么。

| 文件 | 作用 |
|---|---|
| [`task-board.md`](./task-board.md) | 全部任务总表（按模块分类），持续更新状态 |
| [`progress-log.md`](./progress-log.md) | 时间线进度日志（每完成一块追加一条） |
| [`review-log.md`](./review-log.md) | 自审（code-review）发现的问题清单 |
| [`fix-log.md`](./fix-log.md) | 针对自审问题的修复记录（问题→根因→修法→结果） |
| [`test-log.md`](./test-log.md) | 测试结果（单元/集成 + Playwright E2E） |

更新约定：每个里程碑完成后追加日志、回写 task-board 状态。不删历史，只追加。
